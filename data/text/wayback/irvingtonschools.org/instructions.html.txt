This section includes instructions for setting up and styling pages within your Composer website. A default interior page on the website should include a set of banners, and a theme. These banners can be added from the Page Layouts and Appearance menu, which can be accessed by clicking the Page Layout icon located next to the Compose button. From the pop up menu, selections can be made from the dropdown menus.

Header & Footer
Important: Do Not make edits to the default top and bottom banners (header and footer). If you need to make an alternate version of either of these banners, first clone the banner and apply your changes to the clone. Altering the settings in the default banner can and most likely will break the appearance of your site!
Most links in your header/footer can be edited in the Composer sitemap. Below we will note where to find these pages.
| Section | Notes | 
|---|---|
| Header Hamburger Menu (Main Menu) | The pages in the main menu (that you see when you click the Menu button in the header) are found under the site Home page in the main branch of the Composer sitemap. | 
| Header Links | Update these pages in the "Header Portals Nav" or "District Nav" branch of the sitemap. | 
| Find it Fast | Each icon tile in the search menu can be updated under the 'Search Icons Nav' or 'Popular Searches' branch. Each of the pages under Search Icons Nav branch can be given a specific icon from your Icon Library under Page Settings > Custom Nav Class |

Homepage
To ensure proper visual presentation, many elements on the homepage, as well as the header and footer banners, have custom classes added to their settings. These classes are essential for the features to display correctly and should not be removed or modified. Additionally, they are specifically designed for these areas and should not be used on other pages or panels.
For most treatments on the homepage, images are converted to backgrounds and are set to cover the whole container, so in general, using the largest image you have should work fine. Composer will automatically serve smaller versions of each image on mobile breakpoints. If the design shows as portrait orientation it'll generally crop better if the orientation of the original photo is also portrait, same for landscape. If there are any specific image dimensions required for treatments on your homepage, we will list them below, otherwise, just adhere to the minimum width and orientation listed below.
Note*:
The homepage contains a variety of custom treatments that use Javascript code that can interfere with CMS function and editor accessibility. To allow homepage treatments to be accessible for editing, refresh the homepage while the 'COMPOSE' toggle is toggled ON/Blue. This will temporarily disable the custom code tied to the treatments so that everything is stationary and available for editing.
When finished making your edits, refresh the page once more while the 'COMPOSE' toggle is toggled OFF/Grey. This restores the custom code on the treatments so you can preview your work with everything in place.
