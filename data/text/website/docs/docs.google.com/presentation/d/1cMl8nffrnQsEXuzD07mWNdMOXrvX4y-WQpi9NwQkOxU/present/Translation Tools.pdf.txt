How to Translate a PDF or other saved document from one language to another:
 1.  Go to Google Translate.
 2.  Select Documents.
 3.  Select Browse your computer to locate the document you want to be translated.
 4.  To choose the language you want to translate to, click the Down arrow.
 5.  Select Translate.
