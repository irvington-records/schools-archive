If you do not see it in the inventory above, follow the instructions to put in a formal request.
This request process is especially important if you would like students to use the site/app and/or they need to log in/create an account. We need to seek a privacy agreement (EdLaw2d) if this is a tool students need to log into.
Instructions:
- Go to the Approved Software Inventory and search for the tool you're interested in using. If it is on the list, you may use this tool with students. If the tool you are interested in using is not on the list, please follow the information in number 2.
- Secondary teachers should speak with their department chair and principal, and elementary teachers should speak with their team leader and principal about their request.
- REMEMBER: Paid software needs to go through the budgeting process, so if this is a tool you need, have these conversations early in the school year. Non-paid, free software and apps can be reviewed with your building principal at any time. If your principal green-lights the tool, you can email Jerrod to make a formal request. The request submitted is for consideration and is not a guarantee.
